# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use a private
GitHub security advisory for this repository, or contact
cerionegiovanne@gmail.com with the subject `Papergio CLI security`.

Include the affected version, a concise description, reproduction steps, and
the impact. Do not include live credentials or personal data in the report.

We will acknowledge a report as soon as practical and coordinate a fix or
mitigation before public disclosure.
